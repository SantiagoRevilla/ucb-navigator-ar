Sincronizar con Google Calendar y Google Sheets

Esta ventana conecta directamente con la tabla generada por tu script de Google Apps Script (columnas: Nombre del Evento | Ubicación | Fecha y Hora). Pega las filas de tu Google Sheet o prueba los datos de ejemplo:

Ver código Google Apps Script vinculado (Calendar → Sheets) 
function exportarTodosLosEventosASheet() {
  const fechaInicio = new Date();
  const fechaFin = new Date();
  fechaFin.setDate(fechaFin.getDate() + 30);
  const eventos = CalendarApp.getDefaultCalendar().getEvents(fechaInicio, fechaFin);
  const zonaHoraria = Session.getScriptTimeZone();
  const filas = eventos.map(e => [
    e.getTitle(),
    e.getLocation().trim() || "Atrio UCB",
    Utilities.formatDate(e.getStartTime(), zonaHoraria, "yyyy-MM-dd HH:mm")
  ]);
  const hoja = SpreadsheetApp.openById("TU_ID_DE_LA_HOJA").getActiveSheet();
  hoja.clearContents();
  hoja.getRange(1, 1, 1, 3).setValues([["Nombre del Evento", "Ubicación", "Fecha y Hora"]]);
  if (filas.length > 0) hoja.getRange(2, 1, filas.length, 3).setValues(filas);
}
